Назначение и ответственный

AI PVZ Archive используется владельцем проекта AI PVZ Assistants для резервного копирования и восстановления своих рабочих данных. Контакт по вопросам доступа, удаления и конфиденциальности: ai.supervisor.pvz@gmail.com.

Какие данные используются

Архиватор обрабатывает выбранные локальные рабочие файлы и согласованный снимок базы, создаёт зашифрованный архив и использует Google Drive для его хранения. Для доступных приложению объектов Drive могут читаться имя, идентификатор, размер, расположение и контрольные суммы; содержимое зашифрованных архивов скачивается для проверки или восстановления. OAuth-токены используются для выполнения разрешённых пользователем операций.

Разрешения и цель обработки

Собственное OAuth-подключение настраивается с правом drive.file для файлов, созданных приложением либо явно выбранных пользователем для работы с ним. Данные используются только для резервного копирования, проверки целостности и восстановления, не для рекламы, продажи данных или обучения обобщённых моделей искусственного интеллекта.

Хранение и передача

Архивы шифруются AES-256 на компьютере до отправки в Google Drive. Google получает зашифрованные файлы и служебные метаданные. Авторизация хранится в защищённой локальной конфигурации вне репозитория; пароль архива не публикуется и не включается в архивные отчёты. Локальная расшифровка выполняется для проверки и восстановления. Доступ к восстановленным данным предназначен только для уполномоченного владельцем использования.

Приложение не публикует архивы на этом сайте и не продаёт Google user data. Использование и передача информации, полученной через Google API, соответствуют Google API Services User Data Policy, включая требования Limited Use.

Срок хранения, удаление и отзыв доступа

Архивная цепочка сохраняется до решения владельца об удалении; фиксированный срок автоматического удаления не установлен. Удаление отдельных инкрементов может нарушить восстановление. Пользователь может отозвать разрешение приложения в настройках Google-аккаунта. Отзыв прекращает последующий доступ, но сам по себе не удаляет уже созданные локальные или облачные копии. Их удаление согласуется отдельно с владельцем через указанный контакт.

Изменения

При изменении обработки данных публикуется новая редакция с обновлённой датой. Расширение доступа к Google Drive требует отдельного согласия пользователя.
